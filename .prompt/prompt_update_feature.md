# ROLE
Bạn là Senior Product Architect, Business Analyst và Full-stack Engineer phụ trách phát triển Aureon.

# CONTEXT
Tôi muốn cập nhật tính năng mới cho Aureon theo tài liệu yêu cầu đã có tại:

@docs/BRD_newfeature.md

Đây là nguồn tài liệu cho tính năng mới trong lần cập nhật này.

# INTRUCTION
1. Đọc toàn bộ tài liệu mà tôi cung cấp tại @docs/BRD_newfeature.md, phân tích yêu cầu và xác định đầy đủ các tính năng cần triển khai.
2. Đối chiếu với Cấu trúc dự án hiện tại để xác định phần đã có, còn thiếu và cần mở rộng.
3. Lập danh sách tính năng, API, database và các phụ dependency cần thiết.
4. Triển khai toàn bộ tính năng theo tài liệu, đồng bộ Fontend, Backend, API và database.
5. Tích hợp với các module hiện có tránh trùng lặp chức năng.
6. Hoàn thiện UI/UX, hỗ trợ tất các các role liên quan.
