## 2. Files added in this work

- **`DOC-09-hoa-don-gtgt-mau.pdf`** — a single Vietnamese VAT invoice (hóa đơn GTGT) whose text
  layer contains every `INVOICE` schema field: `invoice_number HV-2026-0912`, `issue_date
  12/09/2026`, `seller_name Công ty TNHH TechSoft`, `seller_tax_code 0305551234`, `subtotal
  250.000.000`, `vat_rate_pct 10`, `vat_amount 25.000.000`, `total_amount 275.000.000`. The
  cross-field rule **VR-INV-05** holds (`250.000.000 + 25.000.000 = 275.000.000`). This is the
  canonical end-to-end INVOICE extraction sample.
- **`DOC-10-anh-hoa-don-gtgt.png`** — the same invoice rendered as a photo-like PNG. Uploading it
  (or capturing it via "Chụp ảnh") exercises `preprocess._ocr_image`. With `OCR_PROVIDER=stub` it
  routes to `NEEDS_REVIEW` with empty fields (honest, no fabrication); with `OCR_PROVIDER=paddle`
  the text is recovered.

## 4. Regenerating the set

Deterministic and idempotent — safe to re-run; it overwrites `data/` in place.

```bash
uv run --group demo python scripts/gen_demo_docs.py
```

The generator asserts hard invariants before writing (e.g. Σ of the 47 invoice subtotals =
8,500,000,000; Σ of 45 active salaries = 855,000,000; DOC-09 VR-INV-05). A failed invariant aborts
with a clear message rather than writing wrong data. The generator uses only `openpyxl`,
`python-docx`, `reportlab`, `pillow` (the `demo` dependency group, DEC-120) — no network, no real
data.

## 5. Loading samples into the running system

Samples are **input files**, not seed rows — they are processed through the real pipeline, not
inserted directly. Upload via the UI ("Thêm dữ liệu" → DropZone → Gửi) or via the API:

```bash
# login → access token (demo password from .env DEMO_*_PASSWORD)
TOKEN=$(curl -s -X POST http://localhost:4000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"office@abc.demo","password":"<DEMO_EMPLOYEE_PASSWORD>"}' \
  | python3 -c "import sys,json;print(json.load(sys.stdin)['data']['access_token'])")

# upload one invoice (Idempotency-Key MUST be a UUID)
curl -s -X POST http://localhost:4000/api/v1/idp/documents \
  -H "Authorization: Bearer $TOKEN" \
  -H "Idempotency-Key: $(python3 -c 'import uuid;print(uuid.uuid4())')" \
  -F "document_type=INVOICE" \
  -F "files=@data/DOC-09-hoa-don-gtgt-mau.pdf;type=application/pdf"
```

Re-uploading the same bytes returns `DUPLICATE` (SHA-256 dedup) — expected and safe.
